Как открыть

Запустите Shelf.exe в этой папке. Откроется окно программы.

Как пользоваться

«Добавить» создаёт карточку. Укажите название. Путь к файлу запуска можно вписать самим или выбрать кнопкой «Обзор». «Добавить обложку» ставит вашу картинку. Рабочую папку и аргументы программа не спрашивает.

Карточки можно переставлять: зажмите левую кнопку мыши и перетащите карточку. Если отпустить её на другой карточке, обе соберутся в папку. Папку можно назвать. Карточку можно также положить в уже существующую папку.

Внутри карточки: «Play», «Править», сменить обложку или удалить карточку. «Править» меняет название, путь, папку и теги у уже существующей карточки. «Play» открывает файл так же, как двойной щелчок по нему, из его собственной папки: подойдёт и игра, и лаунчер, и любой другой exe. Если файл не открылся, программа сообщит об этом и отсчёт не начнёт. Если учёт времени включён и файл открылся, счёт начинается сам и сам останавливается, когда этот exe закрывается. «Закрыть сессию» останавливает раньше. Обложки и файлы добавляете вы. Программа их не приносит и не снимает с них защиту.

Язык окна не выбирает право страны и ничего не подтверждает. Кратко о лицензии и о законах — в разделе «О программе».

A local shelf for games. The catalogue is the file shelf-data.json in this copy's folder. Another folder with its own copy does not see it. There is no account. The catalogue is not sent anywhere.

How to open

Start Shelf.exe in this folder. The program opens in its own window.

How to use it

Add creates a card. Enter a title. Type the launch path yourself, or choose the file with Browse. Add cover sets your own picture. The program does not ask for a working folder or for arguments.

Cards can be moved: hold the left mouse button and drag a card. If you drop it on another card, the two become a folder. The folder can be named. A card can also be dropped into a folder that already exists.

Inside a card: Play, Edit, change the cover, or delete the card. Edit changes the name, path, folder and tags of a card that already exists. Play opens the file the same way a double-click would, from that file’s own folder: a game, a launcher, or any other exe. If the file does not open, the program says so and the count does not start. When time tracking is on and the file did open, the clock starts on its own and stops when that exe closes. End session stops it sooner. You add covers and files. The program does not fetch them and does not remove their protection.
